# Final submission checklist
**Focus:** verify completed work. Tick only when true. This checklist is a working aid, not a substitute for report content.

## Required work
- [ ] Site is eligible, has a public form/search and is claimed on LMS.
- [ ] README identifies student, website/organisation/purpose, actual audit date/browser and tiers.
- [ ] A1-A7 completed with site-specific facts and interpretations.
- [ ] A2 contains five actual URLs assessed against all five rules.
- [ ] B1-B8 completed with original evidence or a clear safe-testing limitation.
- [ ] B1 has 2-3 timed captures; network is restored after B1/B3.
- [ ] B5 covers every field; B6 records a real keyboard task.
- [ ] B7 has homepage and inner-page scores, both exports, and up to three actual issues.
- [ ] Part C has two evidence-backed strengths and three ranked recommendations.
- [ ] Every recommendation states problem, evidence, affected users, plain fix, effort and impact.
- [ ] One sentence explains the priority order.
- [ ] Owner summary matches the report and explains a simple verification step for each fix.

## Evidence and integrity
- [ ] All observations, measurements and screenshots are my own and date/URL consistent.
- [ ] Screenshots show site address and relevant DevTools; dates/times are recorded and visible as required.
- [ ] Evidence log has one row per actual file, with timestamp/timezone and exact page URL.
- [ ] Every report evidence ID resolves to the correct evidence file(s).
- [ ] No real forms sent, personal data entered, scanners used or owner contacted.
- [ ] AI-use disclosure accurately describes assistance.
- [ ] Course-only report/evidence access is arranged with instructor; public/private access conflict clarified.

## Export and repository
- [ ] Replace all [FILL] placeholders; remove template comments and guidance from final PDFs.
- [ ] Export drafts/report.md as report.pdf at root: at most 6 main pages plus appendix.
- [ ] Export drafts/owner-summary.md as owner-summary.pdf at root: one page.
- [ ] Open both PDFs and check every page for readability, clipped tables and broken characters.
- [ ] Optional S1/S2 files are exported if attempted; unused templates removed or marked not attempted.
- [ ] Optional fix is original, runs standalone and has before/after evidence if attempted.
- [ ] Work is on assignment/field-study with 4+ meaningful commits over 3+ genuine days.
- [ ] Merge finished work into main, check submitted files there, and submit repository link on LMS by Week 6, 23:59 (confirm exact date).
